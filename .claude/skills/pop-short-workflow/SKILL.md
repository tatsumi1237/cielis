# ポップ・ミニチュア風ショート（pop-short-workflow）

`moshimo-workflow` の派生。**制作の技術基盤は `moshimo-video-build`（`assets/hq/`・`build-hq.sh`・`render*.js`）をそのまま使う**（コピーせず参照）。変えるのは「テイスト」と「構成の型」だけ。
各段階の終わりで必ず止まり、ユーザーのOKを待つ（先回りして動画を書き出さない）。

## もしもシリーズとの違い
| 項目 | もしも（元） | ポップ版（本スキル） |
|---|---|---|
| ネタ | 災害・消滅などのシミュレーション | 雑学・比較・数字ネタ（「〇〇は何個分？」「1日で〇〇すると？」） |
| 冒頭 | 3秒カウントダウン＋SIMULATION | **カウントダウンなし**。1秒目から主役が動き、中央に問い1行 |
| 色 | 夕方の逆光・彩度控えめ〜昼 | **明るいパステル＋高彩度**（`references/taste-pop.md` の `TODP.pop`） |
| カメラ | 主人公の追従・ローアングル | **斜め俯瞰のミニチュア（ティルトシフト風）**＋ときどき寄り |
| 世界 | 実寸の街 | 小さな箱庭・ジオラマ。人物は小さく丸く、色数は絞る |
| 音 | 緊張・不穏のパッド＋鼓動 | 軽いマリンバ/ベル系BGM（C長調・100〜115BPM）＋ポップな効果音 |
| 文字 | しっぽり明朝・金→朱 | 丸ゴシック太字（Zen Maru Gothic 等）＋白縁＋ビビッド1色 |
| 尺 | 約50秒 | **25〜35秒**（1カット2〜3秒、最後=問い＋フォロー誘導1.5秒） |

## 守ること（元スキルから引き継ぐ）
- 品質基準v2：`PP.render` のポスト処理・`skyDome`＋`envFrom` の環境光・`person2()` の滑らかな人物。**箱だけのモデルは不可**（角丸・カプセル・球で作る）
- 数字は公的資料で確認し出典と年次を控える。確認できない数字は使わない
- 全画面1枚の絵。分割画面・グラフ・統計スライドは使わない。大見出し1行＋補足1行まで、数字は1場面に1つ
- 隣り合うカットで絵・色・アングルを変える。変化はカット内で完了させる
- 実在の警報音・既存キャラ・特定の国や民族の揶揄は使わない
- IGセーフゾーン：上0–250・下1700–1920・右下アイコン帯に重要情報を置かない
- 生成AIや素材ファイルは使わない（Three.js＋HTML/CSS、numpy合成の音、Playwright→ffmpeg）

## 流れ
| 段階 | Claudeがすること | 参照 | 止まる条件 |
|---|---|---|---|
| ① テーマ受領 | 解釈が分かれるときだけ1点質問 | — | テーマ確定 |
| ② 構成 | 数字をリサーチ→番号付きカット表（カット｜秒｜見出し／補足｜絵・カメラ）→冒頭の問い・締めの問い・A/B 2択をチャットに出す | `moshimo-storyboard` の進め方（尺・冒頭・締めはこのスキルの表に読み替え） | 「構成OK」 |
| ③ 代表画像 | 各カット1枚を `TODP.pop` で作り、`all_cuts.jpg`＋`cut01.jpg`〜を `代表画像_<テーマ>/` に保存して送る。**原寸で自分も見て**隠れ・文字重なり・白飛びを確認。指摘カットだけ撮り直す。動画はまだ書き出さない | `moshimo-video-build` 手順1〜4 | 「この絵で動画にして」 |
| ④ 動画 | 全編を8並列で書き出し、待つ間に音を作って合成。高画質版＋30MB未満のスマホ版の2本。修正は該当秒数だけ撮り直し | 同 手順5〜9 | 「これで完成」 |
| ⑤ 投稿文 | 完成版に合わせて投稿文・固定コメント2択・ハッシュタグ5個・出典を `投稿文.md` に保存 | `moshimo-post-writer` | 納品 |

## ② 構成の型（ポップ版）
- **カット1（2秒）**：主役のミニチュアがすでに動いている。中央に問い1行（例「東京ドームに〇〇は何個入る？」）。カウントダウンはしない
- **カット2〜**：1カット2〜3秒、**1カット1つの数字・1つの驚き**。「小さな例 → 大きな例 → 想像を超える例」と段階的にスケールを上げる
- **たとえは誰でも知る物**（東京ドーム・スカイツリー・25mプール）。倍率が小さい比較は弱い
- 最後（1.5秒）：視聴者に返る問い＋「フォローで次のネタが届きます」＋コメント2択への誘導
- 終わったら、見出しの数字と出典を表にまとめて渡す

## ③④ 実装のメモ
- 作業開始：`bash <スキルのフォルダ>/moshimo-video-build/build-hq.sh <workdir>`（スキルのフォルダ＝このスキルの1つ上。ローカルなら `~/.claude/skills`、リポジトリ／クラウドなら `<repo>/.claude/skills`）。シーン先頭で `TOD=TODP.pop` を代入（`references/taste-pop.md` のプリセットを scene.js 冒頭に貼る。元の `hq-core.js` は書き換えない）
- カメラ：高さ25〜40m・俯角45〜60°の斜め俯瞰、画角を狭め（FOV 22〜30）て望遠の圧縮感＝ミニチュア感。手前と奥をぼかす（`PP.render` の `dof`）。寄るカットは低め・広角ぎみ
- 動き：小物が弾む・ポップインする（`1-(1-t)^3` のオーバーシュート）。人物は `walk()` の振幅を大きめに
- 文字：丸ゴシックを `document.fonts.load` で読み込んでから描く。見出しは白文字＋太い縁取り＋影、キーワードのみビビッド1色
- 音：`references/taste-pop.md` の音の方針に従う。見出し=pop、場面頭=軽いwhoosh、数字の山場=ベルのきらめき、締め=ベル。仕上げは1秒ごとのRMSで無音がないか確認し、tanhで軽くリミット
- 並列書き出し・検査・圧縮は元スキルの手順と同じ（枚数＝尺×30、音声長＝動画長、`select=…,tile=` で各カットを目視）
