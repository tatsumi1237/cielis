# もしもリール①：構成を整える（moshimo-storyboard）

3スキルの1番目。**テーマ → 確定した構成表**までが担当。映像の実装は `moshimo-video-build`、投稿文は `moshimo-post-writer`。
ユーザーは会話しながら少しずつ詰める。**各ステップで聞くのは1点だけ**。依頼が明確なら質問より先に調べ始める。

## 出力（次のスキルに渡すもの）
1. 数字の前提と出典（調べた事実）
2. **番号付きカット構成表**（下の形式）
3. 冒頭の設計（中央配置・動かすもの）
4. 締めの一言と、最後のフォロー誘導の文言
5. 再利用するモデル／新規に作るモデル
6. （必要なら）冒頭3案、全カットのイメージ画像

## 進め方
### Step 1 テーマ受領 → 数字の土台をリサーチ（質問より先）
- 現在の数字は **WebSearch/WebFetch で公的資料を確認**（内閣府・気象庁・総務省・厚労省など）。記憶の数字は使わない。年次を控える
- 計算できるものは Python で計算し、前提（家族構成・地域・年度）をメモ
- 「◯時間後」「◯年後」「◯倍」「◯個分」のように、**誰でも一瞬で想像できる具体的な数字・たとえ**を探す（ぼかさない）
- 科学的予測がない部分は「想定」と注釈に書く前提で組む。噂・未確認情報は事実として扱わない
- 実在の災害・地名は自治体／国の資料で数値確認。不確かなら架空にする
- 実在の国・民族を揶揄する見せ方にしない。既存キャラクターは描かない

### Step 2 構成表を提示（チャット、表形式）
列：**カット（1から連番）｜時間｜タイマー表示｜絵の種類・カメラ｜大見出し（＋補足1行）｜3Dモデル（再利用／新規）**
- **尺のルール（ユーザー指定・必須）**：**カット1＝3秒（起点の3秒前からカウントダウン）**／**カット2＝3秒**／**カット3以降は1カット4秒以下**／**最後は「視聴者への問い（締めの一言）＋フォロー誘導」を1カット・1秒にまとめる**。全体は約50秒前後になる。
- **映像の質（ユーザー指摘・必須）**：角ばった箱モデル・単調なアングル・ぎこちない動きは不可。滑らかな人物モデル、ポスト処理（ブルーム・色調・ビネット・被写界深度）、環境光、映画的なカメラワーク（追従・寄り・肩越し）で「引き付けられる絵」にする。冒頭のタイトルとカウントダウンは画面中央、フォントと色にこだわる。見せ場は8〜11カット
- 1カットを分けるときは枝番（10-1, 10-2）。ユーザーは「6カット目」と番号で修正指示してくる
- カットを増減したら番号を振り直して表を出し直す
- 続けて「数字の前提」「冒頭の設計」「締めの一言」「音の方針」を短く、最後に **決めてほしいこと1点**

### Step 3 修正を反映 → 全カットのイメージ画像 → 承認後に制作へ
- 構成が固まったら、**本編の書き出し前に各カットの代表1枚を本編と同じ3D（品質基準v2）で作って見せる**（作り方は `moshimo-video-build`）
- 送るときはカット番号ごとに「この絵のあと何が動くか」を1行で添えた表を付ける。個別画像＋一覧(all_cuts.jpg)を送る
- 「これで作って」で制作開始（`moshimo-video-build`）。TaskCreate で進捗を出す

## 構成の決まり
**絵と情報**
- 常に全画面1枚の絵。上下分割・左右比較・ワイプ・グラフ・統計スライドは使わない
- 1場面の文字は「大見出し1行＋補足1行」まで。数字は1場面に1つ（原則補足行）。絵を見ただけで意味が伝わる大見出しにする
- 章番号ヘッダーは出さない。時間の流れ（何日後／何年後）は**タイマー（経過時間またはカウントダウン）**で1本の流れにする
- **隣り合うカットで絵の種類（実景・地球・年表・群衆・クローズアップ…）、色、アングルを必ず変える**。同じカメラで何カットも使い回さない
- 「だんだん完成していく」1本調子は間延びするので避ける。**視点を変えて1カット1つずつ**見せる（大きさ→数→時間→人、または時系列の段階ごと）
- 比較は倍率が小さいと弱い（3.8倍は却下された）。誰でも知る物を積み上げる・並べる（スカイツリー何本分、家何軒分）
- 変化はカットの中で起こして完了させる（水が上がって電車が沈む、など）。最初から完了した状態にしない
- 動物は吹き出しで名前を出す。人物を寄りで見せるなら高精細(HD)で手足あり、人数は絞る
- 地球・年表・数値の「何個分」などは**動画と同じ3Dで**描く（2Dの図やイラストは却下された）

**冒頭（カット1＝3秒、カット2＝3秒）**
- **動画は「発災・変化の起点の3秒前」から始める**（タイマーは起点までのカウントダウン3→0、その後は経過時間）。カット1の大見出しは「もしも〇〇が起きたら」（テーマの問い）、事象はカット2から始める
- **後半の被害・影響は、公的資料の具体数字や実際に起きる出来事（停電・断水・避難者・死者・経済被害額など）でインパクトを出す。物流が滞る、のような抽象的で地味な見出しは避ける。数字は出典のあるものだけ。『車が3分の1になる』のような根拠のない数字は作らない**
- 1フレーム目は**変化前の普通の世界**（明るく鮮やか）。変化後から始めない
- タイトルとタイマーは**画面の中央**に置く（必須）。目安 1080×1920 で タイトル中心 y≈760、タイマー中心 y≈1080。中央に楕円の暗いぼかしを敷く
- 3Dの主役は文字の上下（上1/4か下1/3）に見えるようカメラを振る。冒頭が終わったらタイトルは1行に縮めて上部(y≈70)、タイマーは縮小して上部(y≈170)へ移動し、以降は固定（v2の目安：主人公の頭が y≈1400、上半分は見上げたビルと空）
- 0〜3秒は場面転換・フラッシュなし。ただし**カメラ・手前の物・背景の人や車・自然・変化の予兆のうち3つ以上を動かす**（止まった絵を作らない）
- 最初の大きな変化が起きる瞬間だけ白フラッシュを使ってよい
- タイトルは「もしも〇〇が〇〇だったら？」型の1つの問い。強調語は1つだけ色を変える
- デザインは **品質基準v2の「シネマ型」で固定**（`moshimo-video-build` の `assets/hq/head.html`）：中央に SIMULATION の小見出し、「もしも」＋**キーワード大（しっぽり明朝B1・白→金→朱のグラデ）**＋後半、その下に**Oswaldの光る大カウントダウン3.00→0.00**と進行バー。冒頭3案は作らない（デザインは確定済み）
- **冒頭の型（合格例）**：カット1＝普通の日常を主人公が歩く（ローアングル追従、周りにも人が行き交う、夕方の逆光）／カット2＝起点の瞬間、肩越しに手元へ寄り、スマホ等の「異変を知らせるもの」を見せる（背景ぼかし、周りの人も一斉に反応）。テーマが違っても「主人公の日常→異変の知らせ」の流れで組む
- 時間表示：ユーザーが「経過時間」と言えば経過時間、そうでなければ「〇〇まで」のカウントダウン

**締め（最後の1秒：締めの問い＋フォロー誘導を1カットにまとめる）**
- 締めは**視聴者自身に返ってくる問い**（例：あなたの避難先、決めてる？）。単独のカットにせず、フォロー誘導カードの一番上に大きく置く
- **1秒のカード**（次回予告は入れない）。最後の映像を暗くして、上に締めの問い、その下に：
  ```
  この動画が面白かったら
  フォローで 次の「もしも」が届きます   ← 明朝・「フォロー」だけ橙
  ［＋ フォローする］                     ← 橙の丸ボタン風
  コメント欄の2択にも 答えてね👇
  ```
- 締めの内容から自然に選べる **A/B の2択** をこの段階で決めておく（`moshimo-post-writer` に渡す）

**音の方針（構成表に1〜2行）**：ナレーションなし。BGM（テーマに合う調・BPM）＋カットごとの環境音／効果音。見出しの出現に pop、場面頭に whoosh。

## 構成表の見本
| カット | 時間 | タイマー | 絵 | 大見出し／補足 | モデル |
|---|---|---|---|---|---|
| 1 | 0–5 | 経過 0:00 | 昼の交差点・人が歩く（寄り・HD） | 「世界から人間が消える」 | human(hd) 再利用 |
| 2 | 5–11 | 3時間後 | 夜の街・明かりが消える（俯瞰） | 「電気が止まる」／発電所は自動停止 | city 再利用 |

## 完成前チェック（すべてYESで構成確定）
- [ ] 数字は最新の公的資料で確認し、出典と年次を控えた
- [ ] 全カットに1からの番号がある。隣り合うカットで絵・色・アングルが違う
- [ ] 1フレーム目は変化前の明るい普通の世界。冒頭のタイトル／タイマーは中央配置
- [ ] カット2が3秒・カット3以降が4秒以下・最後は締めの問い＋誘導の1カット1秒
- [ ] 大見出し1行＋補足1行以内。グラフ・分割画面・章ヘッダーがない
- [ ] 変化がカット内で完了する。数字は具体的（24時間、50年後 など）
- [ ] 締めの一言＋2秒のフォロー誘導＋A/B 2択が決まっている
- [ ] 再利用／新規モデルを分けて伝えた。決めてほしいこと1点で終えた
