# 間延びさせない工夫と、カットの作り方

「もしも、人類が100人になったら？」で実際に使い、ユーザーのOKが出た手法。**新しい動画のカット表を作る時に、各カットにこの中のどれを使うかを書く。**

## 1. カットの割り方（離脱させないテンポ）
- **台詞1文＝1カット**が基本。1カットは **1〜4秒**。4秒を超える台詞は、意味の区切り（「つまり／○○して／○○して／暮らすのです」）で **2〜3カットに割る**。
- 終盤（まとめ・オチ前）ほど単調になりやすい。**後半ほどカットを細かく**（キャンプは6カットに割った）。
- 同じ場面を続ける時も、**寄り・引き・別の角度・別の小道具**に切り替えて「新しい絵」を出す。
- 列挙の台詞（「海も、ゴルフ場も、道路も」）は、**1語ごとに場面を切り替える**（0.75〜1秒のカットでよい）。

## 2. カメラ（止めない）
- **カメラは常に動かす**：押し込み（ドリー）・引き・回り込み（オービット）・上昇（クレーン）・らせん降下・並走。
- 「広さ」：主役のアップ → 指数的に距離を伸ばして米粒サイズまで引く（9m→235m）。
- 「たった1人／1台」：主役を画面の下寄りに小さく残し、上に地平線と空。
- 速いもの：迫ってくる被写体を前斜めから → カメラが減速・上昇して追い抜かれる → 上空から全体。
- 室内の締め：最後の1.5秒でカメラが小道具（モニター）へ寄る。
- 近い人物カットは、**ごくわずかな手持ち風の揺れ**（数cm）で臨場感。
- 縦画面は左右が狭い（水平の画角は約25°）。**主役は画面の中央付近**に置く。並んだ2人を撮るなら距離を取るか、奥行き方向に並べる。

## 3. 「変化」を見せる（数字・状態が動く）
- 数が**減る**：人が光の粒になって消えていき、最後の1人に寄る。カウンターは対数で減らす（80億→100）。
- 数が**増える**：1人 → 中心から渦を巻くように加速しながら100人。カウントアップ表示（1人→100人で金色に）。
- 状態が**消える**：夜の街の明かりが、一点から波のように消えていく（窓ごと・街灯ごとに消える時刻を持たせる）。
- **降ってくる・ポンと出る**：日本列島が×4で降ってくる、ピンが波紋のように立つ、人が一列ずつポップイン。
- **比較**：いる100人（色付き）と、足りない数百人（半透明の影）。1000人の中で医師2人だけ光る（他は暗く）。

## 4. 人物と小道具（「一人で過ごす」）
- 人物は確実な動きだけ：**歩く・座る・寝転ぶ・立つ**（パットやスイングのような細かい動作は作らない）。
- 状況は**小道具**で伝える：麦わら帽子とドリンク（海）、クラブ（ゴルフ）、カート（スーパー）、鍬（畑）、缶詰（キャンプ）、ギター（団らん）。
- 「独占・貸し切り」は、**その場所に一人だけ**いる絵にする。
- 群衆は、それぞれ違う服の色にして、歩き方の位相もずらす。

## 5. 背景で埋める（空白を作らない）
- 引きの画面に何もない地面を残さない。テーマに合う背景を足す：牧場（柵・牛・羊・干し草・納屋・サイロ）、住宅街（家・塀・木・道）、キャンプ（テント・森・松明）。
- 空は雲のある青空・夕焼け・星空を使い分ける。夜は星と月、最後に**流れ星**。

## 6. 音（映像と同期）
- 場面ごとに環境音（雑踏・波・鳥・虫・風・店内・たき火）。
- **映像の動きに同期した効果音**：消える瞬間のキラッ、ピンが立つポッ、日本が降りるポン、増えるポポポ、ブレーカーのカチッ、火花のバチッ、心電図のピッ。
- 曲で緩急：明るい曲 → 「でも実は」で止めて暗い持続音 → 重い話題の締めで**音楽を止めて「ピー」だけ** → 明るい曲が戻る → 最後は温かい和音と鐘。
- 声が出ている間は BGM を自動で下げる（ダッキング）。

## 7. オチ・締め
- 重い話題の締め：画面内の機器が変わる（心電図が平らに・HR 0 が赤く点滅）＋音。
- 最終オチ：字幕を**声に合わせて1行ずつ画面中央**に出す（「……つまり」「人類が100人になったら」「最終的に」「みんなでキャンプになります」）。最後は引いて暗転。

## 8. 内容との矛盾チェック（必須）
小物・光・音を足すたびに台本と照合する。例：「電気の無い中」→ 電球・光るテント・電気ランタン・街灯は禁止（明かりは火・月・星）。「人類100人」→ 群衆を写すなら人数の扱いをはっきり（画面上は1人まで、など）。
