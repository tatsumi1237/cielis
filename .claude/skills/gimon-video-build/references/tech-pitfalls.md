# 技術的な落とし穴と対処（three.js ＋ Playwright 書き出し）

実際に起きた不具合と、その直し方。同じ症状が出たらここを見る。

## ピンぼけ・ぼやけ（最重要）
| 症状 | 原因 | 対処 |
|---|---|---|
| 遠景が常にぼける | BokehPass は aperture を小さくしても `maxblur` の上限まで遠景をぼかす | **BokehPass を無効**（`bokeh.enabled = false`） |
| 動くカメラで絵がにじむ | シャッター時間をずらしてサブフレームを重ねる「動きのブレ」 | **使わない**。サブフレーム6枚は同じ瞬間を Halton 列で1px未満ずらす（`camera.setViewOffset`）だけ |
| 全体が眠い | 光のにじみ・色収差・粒子 | ブルーム強さ0.1前後・半径0.35、色収差0、粒子0.008以下、仕上げに4近傍アンシャープ（0.45） |
| 共有版がぼやける | 強い圧縮（crf 23＋上限ビットレート） | 共有版は **2パス・7〜9Mbps**。30MBに収まらない長さは**分割**して送る |

## 描画のおかしさ
| 症状 | 原因 | 対処 |
|---|---|---|
| 出る前の透明な輪・影が「暗い丸」で見える | GTAO（物陰の暗さ）が透明物を不透明として描く | 透明物・加算の光・粒子は**シーンの fx リストに入れ、GTAO の描画中は非表示** |
| 草が黒い線になる | 両面描画の裏面で法線が反転 | フラグメントで `normal = normalize(vNormal)` に戻す |
| 消えた人の平たい欠片が地面に残る | 高さだけ0にして横幅を残した | 消えきったら**全方向0**に縮める |
| 空が真っ黒 | カメラの far（3000）が空の球（8000）より短い | far を 12000 に |
| 文字が画面からはみ出す | 長い数字・長い行 | 数字は幅を測り、はみ出す時だけ**font-size を下げる**（transform で縮めると中心がずれて切れる）。行は `white-space:nowrap` で、長い文は改行 |
| 縦画面で人物が切れる | 水平の画角が約25°しかない | 主役を画面中央付近に。並ぶ2人を正面から撮らない |
| 逆光で小物が真っ黒 | 光源の反対側から撮影 | 光源の横方向から撮るか、小物の近くに弱い点光源を足す |

## 書き出し・音
| 症状 | 原因 | 対処 |
|---|---|---|
| PowerShell スクリプトの param が効かない | Windows PowerShell 5.1 は BOM なし UTF-8 を誤読（日本語コメントで行が壊れる） | **.ps1 は英語（ASCII）だけ**で書く |
| 送れない | SendUserFile の上限は30MB | 2パスで約7Mbps、それでも超えたら分割 |
| 全部を描き直して時間がかかる | — | 変えたカットの**フレーム範囲だけ**書き出して、連番に上書き。テロップを変えた時は全編 |
| 音量が前の版から変わる | 効果音全体をピークで正規化している | 大きな低音（ドーン）を入れすぎない。最終は -16 LUFS 前後のナレーション＋ダッキング |

## 書き出しの速さ（目安：AMD 内蔵GPU、1080×1920、サブフレーム6）
- 1フレーム 0.2〜0.4秒。87秒（2616フレーム）で約12〜15分。長いものは裏で実行し、完了通知を待つ。
- 試し撮りはサブフレーム1（`SUB=1`）で、数コマを横に並べた比較画像で確認する。

## Linux／クラウドで書き出すとき
| 症状 | 原因 | 対処 |
|---|---|---|
| 字幕が四角（□）になる | 日本語フォントが無い | `apt-get install -y fonts-noto-cjk`（Noto Sans JP 相当）。`fc-list | grep -i cjk` で確認 |
| 書き出しが非常に遅い／WebGL が使えない | GPU が無い | `render.js` は Linux で SwiftShader（ソフトウェア描画）に自動で切り替わる。`SUB=1` で試し、本番は範囲を絞って裏で実行する |
| `playwright が見つかりません` | ルートに入れていない | `<project>/` で `npm i three@0.160.0 playwright && npx playwright install --with-deps chromium` |
| index.html で three が読めない | importmap のパス | `/node_modules/three/...`（ルートに `node_modules` がある前提）。ルートで `render.js` を実行する |
