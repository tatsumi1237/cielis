# テロップ・数字の仕様書（1080×1920）

「もしも、人類が100人になったら？」で実際に使い、ユーザーのOKが出た数値。**新しい動画はこの表のとおりに作る。** 実装は `assets/index.html`（CSS）と `assets/example-scene.js` の `SUBS`（字幕の一覧）・`setDOM`（表示）。

## 共通
- 書体 **Noto Sans JP**、文字は白、**黒の縁取り**（上下左右3pxの影＋ぼかし影）。強調語は金色 **#ffd75e**（赤い補足は #ff6b5b、水色は #7fd8ff）。
- 字幕は `<span class="ln">` で**1行ずつ** `white-space:nowrap`。行は `<br>` で区切る。
- フェード：出る0.12秒／消える0.08秒。出る時刻＝その台詞の声の開始、消える時刻＝声の終わり（次の字幕の直前）。
- 字幕と字幕の間に**空白（字幕なし）を作らない**（0.05〜0.1秒の隙間だけ）。

## 安全枠（左右が切れる問題・2026-10-30 に判明）
Instagram は9:16（1080×1920）の動画を、縦長スマホの再生画面に**動画の高さ基準で拡大して表示し、左右をカットする**。実測（ユーザーの iPhone のスクショと元コマの位置合わせ、相関0.92）：
- ユーザーが見た再生画面（下にコメント欄あり）：拡大率1.186倍、**左右を各47px切る**（見える範囲は x=47〜1034）。
- 全画面のリール画面（画面比 約9:19.5）：高さ基準で拡大すると**各約96px切る**（見える範囲は x=96〜984）。※計算による推定、未実測。
- 動画ファイル自体は正常（1080×1920、SAR 1:1、字幕の切れ0件）。**投稿の不具合ではなく、表示の仕様**。TikTok・YouTube Shorts も縦長画面では似た切り方をする可能性がある（未確認）。

**ルール：文字・数字は x=110〜970（幅860px以内）に収める。**
- 88pxの字幕は**1行9字まで**（約815px）。10字で約906px、11字で約995pxになり枠を超える。114pxは7字まで、64pxは13字まで。
- 大きな数字は、幅が**860pxを超える時**に文字サイズを下げる（以前は1010pxで、左右が切れた）。
- 冒頭タイトル「100人になったら？」（114pxで1040px）のような行は、**3行に割る**か、さらに意味の切れ目で改行する。
- 書き出し前に `assets/measure-edges.js` で全カットの字幕・数字の左右の端を測り、x=110〜970 を外れる行が0件であることを確認する。
- 実際の表示の確認が必要な時は、投稿後のスクショと元コマを `assets/align-screenshot.py` で位置合わせして、切れ幅を測る。

## 句読点（ユーザー指示：改行するなら句読点は不要）
- **字幕の行末の「、」「。」は付けない。** 行の途中の読点、「？」、先頭の「……」、鉤括弧「」は残す。
- 実装の保険：`l.replace(/[、。]+((?:<\/em>)?)$/, '$1')`（行末の句読点を、強調タグの手前でも消す）。**ただしカット表・字幕の一覧を書く段階で、最初から行末に句読点を書かない。**
- 音声用の台本（ElevenLabs に渡す文）は句読点を**残す**（間・抑揚になる）。字幕と音声用で句読点が違うのは正しい。
- 字幕は、台本の句読点・意味の区切りで改行して作る（例：「でも、その後は、畑も家畜も、100人で回すしかありません」→ 4行「でも、その後は／畑も家畜も／100人で／回すしかありません」）。

## 長い行・行数
- **88pxで1行は9字まで**（安全枠の幅860px以内）。「みんなバラバラにならず」（11字）は枠を超えていた。
- 10字以上の行は、**意味の切れ目でさらに改行**して88pxを保つ（例：「世界中の家も／ホテルも」「人が調整し／続けないと」「みんな／バラバラにならず」）。それでも収まらない時だけ、その場面だけ64px（13字まで）に下げる（地図のカットがこれ）。
- 1回の字幕は**最大4行**。4行を超えるなら台詞を2カットに割る。
- 1語だけの字幕（「海も」「ゴルフ場も」）もそのまま大きく出す。

## 強調
- 強調（金色）は**1回の字幕につき最大1語**。核心の名詞だけ（選び放題／貸し切り／人手／缶詰／キャンプ／電気／100人）。
- 数字・単位は強調か、大きな数字の表示にする。

## 未解決・注意
- **日本地図のカットの字幕は64pxのまま**。ユーザーは明示的にOKしたが、「小さい」と再び言われやすい。次の動画は、長い一文を意味で3〜4行に割って88pxを保つ。
- 画面の下端から約300pxは、SNSの操作ボタンで隠れやすい（自分の判断・未検証）。重要な文字は1600px以内に。
