# もしもリール③：投稿文を作る（moshimo-post-writer）

3スキルの3番目（`moshimo-workflow` の⑥）。**ユーザーが動画を「完成」としたあと**、完成版の内容に合わせて、コピペ用コードブロックにまとめて渡し、`投稿文.md` にも保存する。入力は `moshimo-storyboard` の構成表・締めの一言・A/B 2択・出典。

## 目的
フォローとコメントを増やす。コメントは「AかBを打つだけ」で答えられる**2択**にして、ハードルを下げる。次回予告は書かない。

## 構成（この順番）
1. **1行目フック**：「もしも、○○だったら？」＋絵文字1つ。「続きを読む」前の最初の2行に一番強い言葉（具体的な数字・時間）を置く
2. **2行目**：切り口・希少性（例：「24時間後、東京はどうなる？」）
3. **本文**：見せ場を「・」でつないで1行（例：電気が止まる・地下鉄が水没・森が街をのみ込む）＋変化の大きさを一言
4. **続きを見たくなる一文**（オチ自体は書かない）
5. **2択ブロック**（必須）：
   ```
   ━━━━━━━━━━
   💬 あなたはどっち？
   A：〇〇
   B：〇〇
   「A」か「B」だけでもOK！コメントで教えてください👇
   ━━━━━━━━━━
   ```
   2択は動画の締めから自然に選べる内容にする（例：A「人間がいない静かな地球も、見てみたい」／B「やっぱり人間がいる世界がいい」）
6. **フォロー誘導**：「🔔 フォローしておくと、次の「もしも」がタイムラインに届きます」
7. **保存誘導**：「📌 あとで見返せるように「保存」もおすすめ」
8. **注釈**：出典（資料名＋年次）、試算の前提、想定部分は「フィクションの想定です」「数値は一例です」
9. **最終行にハッシュタグ**

## ハッシュタグ
- **1投稿5個まで**（2025年12月〜のルール。不確かなら作る前に WebSearch で確認）
- **必須2つ（表記もこのまま・先頭）**：`#シュミレーション` `#思考実験`
- 残り3つ：テーマ固有の小さめ1つ＋関心層が検索する中規模1つ＋広く届く大きめ1つ
- 納品前に**個数（5個）と必須2つ**を数えて確認する

## 一緒に渡すもの（毎回セット）
1. **投稿文**（上の構成。コードブロック1つ）
2. **固定コメント用の2択**（投稿直後に自分でコメントして固定する文。投稿文の2択と同じ軸で、短く）
   ```
   💬 みんなはどっち？
   A：〇〇
   B：〇〇
   「A」か「B」で教えてね👇
   ```
3. **出典リスト**（Sources：資料名＋リンク）
4. ひとこと：ハッシュタグの選定理由（短く）と、直したい点の確認

## 書き方のコツ
- 答えやすさ最優先：自由記述でなく A/B。選択肢はどちらも言いたくなる立場にする（片方が正解にならない）
- フォローの理由は具体的に（「次の「もしも」が届きます」）。お願いだけで終わらせない
- 数字は動画と同じものを使い、動画と矛盾させない
- 実在の国・集団を煽らない。未確認情報を断定しない
- 絵文字は行頭に少しだけ。段落は短く、空行で区切る

## 見本（形式の見本。中身はテーマで差し替える）
```
もしも、この世から人間が消えたら？🌍
24時間後・50年後・1万年後、地球に何が残るのか。

電気が止まる・地下鉄が水没・東京が森になる・橋が崩れる。
最後に残るのは、石と銅でできたものだけ…
ぜひ最後まで見てください👀

━━━━━━━━━━
💬 あなたはどっち？
A：人間がいない静かな地球も、見てみたい
B：やっぱり人間がいる世界がいい
「A」か「B」だけでもOK！コメントで教えてください👇
━━━━━━━━━━

🔔 フォローしておくと、次の「もしも」がタイムラインに届きます
📌 あとで見返せるように「保存」もおすすめ

※映像は想定によるシミュレーションです。年数・現象は研究や書籍をもとにした一例です
※出典：（資料名・年次）

#シュミレーション #思考実験 #人類滅亡 #地球 #もしも
```

## 納品前チェック
- [ ] 1〜2行目に具体的な数字／強い言葉がある
- [ ] A/B の2択がある（投稿文＋固定コメント用の2つ）
- [ ] フォロー誘導と保存誘導がある。次回予告はない
- [ ] 注釈に出典と年次、想定部分の明記がある
- [ ] ハッシュタグが5個で、先頭が #シュミレーション #思考実験
- [ ] 動画の数字・順番と矛盾していない
