# AI PR動画の制作手順(Higgsfield API + GPT画像 + ffmpeg)

実際に「架空のカー整備会社の求人動画(20秒)」を作って得た、うまくいった手順と落とし穴をまとめたもの。
作業フォルダは案件ごとに作る(例: `work/<案件名>/`)。

## 0. 先に決めること(ユーザーに確認)
- 目的・尺・縦横比(基本 9:16)・解像度(まず480p、仕上げで720p)
- ナレーションの有無と原稿。**ナレーションは別収録を推奨**(下記 3)
- 架空の企業名は、**実在の企業と紛らわしくないか**を確認して一言伝える(例: AUTOBACS に似た名前)
- 化粧品・健康などは薬機法に配慮(効能をうたわず「うるおい」など雰囲気で)
- **費用が発生する操作(生成・入金)の前に、概算費用を伝えて承認を取る**
- Higgsfield API の残高は API から取れない。生成が `not_enough_credits` / `credit balance is too low` で失敗したら、入金(ユーザー本人、最低$5)を依頼する。生成前にConsoleの残高を確認してもらうとよい。OpenAI側も同様に残高切れ(`insufficient_quota`)があり、Whisperによるナレーション確認が使えなくなる
- **Seedanceのネイティブ音声のナレーション(日本語)は品質が不安定**(読み違い・ずれ)。ナレーションが必要なら別収録を使い、Seedanceには効果音とBGMだけを作らせる

## 1. 使うもの・認証(ユーザー本人の操作が必要な部分に注意)
- **Higgsfield API**(MCPではない。MCPの無料プランはSeedance 2.0が使えない): `https://console.higgsfield.ai` でアカウント作成
  - アカウント作成・カード登録・メール認証・入金は**ユーザー本人が行う**(代行不可)。カード登録時に $3 の仮押さえが出る(数日で解除)。入金は最低 $5。**Auto top-up は切るよう勧める**
  - APIキーは**1本の文字列 `ID:SECRET`**。作成直後しか見られないので、画面を閉じる前に、環境変数 `HF_API_KEY`（または作業フォルダの `.env` の `HF_API_KEY=`）に保存してもらう(チャットに貼らせない)。私は値を表示せず、長さとコロンの有無だけ確認する
  - 認証ヘッダー: `Authorization: Key <ID:SECRET>`。リクエストに `Idempotency-Key: <uuid>`
- **GPT画像**(絵コンテ・参照画像): `gpt-image-2`。キーは環境変数 `OPENAI_API_KEY`(または `OPENAI_ENV_FILE` で指定した .env ファイル。値は表示せず、実行時に読む)。参照画像ありは `/v1/images/edits`(`image[]`、multipart)
- **ffmpeg**(PATH 上の `ffmpeg`。別の場所なら環境変数 `FFMPEG` で指定)、必要なら Real-ESRGAN / RIFE(任意のフォルダに置き、`TOOLS_DIR` で指定。GitHub公式から入れる)
- Google ドライブは `G:\マイドライブ\` にマウントされている(コピーすれば同期される)

## 2. 絵コンテ(必ず先に作って承認をもらう)
1. 構成案(カット数・秒数・ナレーション・音・テロップ)を決める。ナレーションは**1秒に約4〜5音**で秒数を見積もる
2. **主人公・商品・店舗など繰り返し出る要素の基準画像を先に1枚作り**、他のカットは `edits` でその画像を参照して作る(顔・服装が揃う)。家族など別人物も、先に作ったカットを参照にして揃える
3. **GPT画像APIの並列は1分あたり最大約5件**(429で弾かれる)。5件ずつに分けて、間を20秒ほど空ける
3. 各画像を**必ず目で確認**(ロゴの欠け、服装の取り違え、顔の崩れ)。ダメなら該当カットだけ作り直す
4. HTML絵コンテ(`references/storyboard_template.html`)に画像・秒数・ナレーション・音・テロップ・タイムライン図を入れる
5. **スマホで見られるようにArtifactで公開**する(画像は幅600のJPGに軽量化し `files` で添付。ローカルHTMLはスマホで見られない)。ダークモード対応・表は横スクロール
6. 絵コンテ上のテロップは仕上がりのイメージとして重ねて見せる(実際は後で入れる)

## 3. ナレーション
- **Seedanceには声を入れさせない**(`NO voice, NO narration` と明記)。効果音とBGMだけ作らせる。2本に分けると声質が変わるため
- ナレーションは別収録のm4aをもらう。`ffmpeg silencedetect=noise=-35dB:d=0.12` で無音区切りを取り、Whisper(`whisper-1`, `language=ja`)の文字起こしで各フレーズの開始・終了秒を測り、**カット切替位置を音声に合わせる**
- 音声ファイルのつもりで届いたものが映像なしのことがある → まず `ffmpeg -i` で中身を確認

## 4. 動画生成(Seedance 2.0)
- エンドポイント(`https://api.higgsfield.ai/bytedance/seedance-2.0/...`): `text-to-video` / `image-to-video` / `reference-to-video`。2.5 は最大30秒、2.0 は **1回4〜15秒**
- ファイル: `POST /files/generate-upload-url` → `upload_url` へ PUT → `public_url` をリクエストに使う
- 非同期: 返ってきた `status_url` を5〜8秒おきにポーリング。完了で `video.url`
- `reference-to-video`: `image_urls` 最大9枚、`duration` 4〜15、`resolution`、`aspect_ratio`、`generate_audio`。**カット数が多いなら10秒×2本に分け、境目を場面転換に置く**
- `image-to-video`: `image_url`、`duration`、`resolution`、`generate_audio`。**縦横比の指定がなく、入力画像の比率に近く出る**(2:3の画像→834x1112になった)
- 480pは実寸 496x864。720pは 720x1280
- **カットの長さはプロンプトで指示しても守られない**。生成後に ffmpeg の `scdet=threshold=12` で実際の切替位置を検出して切り分ける
- 「著作権の制限」で弾かれることがある。同じ参照画像でプロンプトを変えると通る場合がある
- 生成後は音声に声が混ざっていないかWhisperで確認する
- 人物の顔: **小さく写る集合写真は480pだと顔が崩れる**。元の高精細な静止画を `image-to-video` の最初のコマにして、720p・動きは最小(ゆっくり寄るだけ)で作る
- 看板・ロゴの文字は動画で波打ちやすい。カメラはゆっくり・安定、看板は小さく遠くに、と指示する。文字は**後から重ねる**のが基本

## 5. 編集・仕上げ(ffmpeg)
- 切り分けは境目の前後を**1コマ分(1/fps)手前で切る**(隣のカットの1コマが混ざる)
- カクつきの原因は fps 変換での同コマ重複。完成版から `mpdecimate` で**実際に絵が変わるコマだけ**を取り出し、**Real-ESRGAN `realesrgan-x4plus` で拡大 → `scale=720:1254:lanczos` → RIFE `rife-v4.6` で一定60fps**にする(`scripts/upscale_interpolate_pipeline.sh`)。処理は1カット約6〜9分、全体で約1時間(バックグラウンド実行)
- 画面比率が合わない素材は、幅を合わせて**上の空だけ滑らかなグラデーションで延ばす**(`fillborders=smear` は縦筋が出る → 上端数行を大きくぼかして背景にし、元映像の上端をフェザーで重ねる)
- ロゴ・文字は後から重ねる。ロゴ画像はPILで作る(**斜体は右に張り出すので余白を多めに**。切ると「S」が欠ける)
- 音声は完成版/ナレーションを `-map 1:a` で使う。BGMはナレーションより小さく
- 動画の `-shortest` とカット合計の長さを揃える

## 6. テロップのデザインとアニメーション
- 標準的な細ゴシックは安っぽく見える。**明朝体(Noto Serif JP, 可変フォント)の太字、大小の強弱**(キーワードを特大、補足は細く小さく字間を広く)、細い上下線が上品
- PILで `font.set_variation_by_axes([weight])` で太さを変えられる(`NotoSerifJP-VF.ttf` / `NotoSansJP-VF.ttf`)
- 案は**3案を実際の最終コマに重ねて並べて**見せ、選んでもらう → 選ばれた案をアニメーション化
- アニメーション: 1文字ずつ PNG にして `overlay` の y を式で動かし(`30*pow(1-clip((t-T0)/D,0,1),3)`)、`fade ... alpha=1` で出す。線は `drawbox` で中央から伸ばす
- 落とし穴: **静止画の `-i` は `-loop 1 -framerate 60 -t 18` を付けないと、後からのフェードが効かず映らない**。`drawbox` の幅 0 は「全幅」になるので `enable='gte(t,T0)'` と最小幅2pxを付ける。concat リストのパスは作業フォルダからの相対パスにする(`/c/...` はffmpegが読めない)

## 7. 納品
- 最新版を決まった名前(`..._final_720p60.mp4`)で上書きし、前の版は `_v1, _v2` で残す
- 保存場所(フルパス)を必ず伝える。Googleドライブに入れるよう頼まれたら `G:\マイドライブ\<フォルダ>` へコピー
- 動き・音は私には見えない/聞こえないので、**確認できたこと(コマ・文字起こし)と、ユーザーに再生して確認してほしい点**を分けて報告する

詳しい経緯・コードは `scripts/` と `references/` を参照。
