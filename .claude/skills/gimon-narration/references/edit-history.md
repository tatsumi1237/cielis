# 台本の修正履歴と、そこから取り出したルール

テーマ「もしも、人類が100人になったら？」で、Claude の案（v1→v2→v3）をユーザーが直した箇所の記録。**次回からは、この表の右列を最初から台本に反映し、直しを最小限にする。**

## 1. 長さ
| Claude案 | ユーザーの指摘 | ルール |
|---|---|---|
| 冷蔵庫の台本：約230文字・約48秒 | 「流れは問題ないが、長さが短い。最低でも1分以上」 | **約400〜470文字・80〜90秒**を目標にする |

## 2. 言い回し・構成の直し（Claude案 → ユーザー最終稿）
| # | Claude案 | ユーザーの修正 | 読み取れる好み → ルール |
|---|---|---|---|
| ① | 「まず、いいことから。ひとり当たりの土地は…」 | 「まず、ひとり当たりの土地は…」 | **メタな前置き（「いいことから」）は削る。** 本題から入る |
| ② | 「広くて静かで、のんびり暮らせます」 | 「広大な土地を独占して、のんびり暮らせます」 | メリットは**得をした感じが強い言葉**（広大・独占）にする |
| ③ | メリット2つ目：「空気も海もきれいになって、自然が少しずつ戻ってくる」 | 「海も、ゴルフ場も、道路もすべて貸し切りです。」に差し替え | 抽象論・環境の話より、**具体的で絵になる「貸し切り」**。固有の場所を3つ並べる |
| ④ | 「……最高じゃないか、と思いますよね。でも実は、いちばん困るのは「広さ」じゃなくて、「人手」なんです。」 | 「……でも実は、困るのは、「人手」なんです。」 | 転換は**短い1文**。聞き手への問いかけ（「思いますよね」）と対比の説明（「広さじゃなくて」）は削る |
| ⑤ | 「数日もすれば、夜の街から、明かりが消える。」「人が見張って調整し続けないと」 | 「数日で、夜の街から明かりが消えます。」「人が調整し続けないと」 | **ですます調で統一**（常体「消える」は不可）。余分な語（見張って）は削り、読点を減らす |
| ⑥ | ネタ：「新しい道具は作れるのか（スマホ一台に数千の部品）」 | 「緊急性が低い。もっと良いものがありそう」→ 医療に差し替え | デメリットは**命・生活への緊急性が高い順**。電気→医療→食べ物→種の存続 |
| ⑦ | 「世界の医師は、人口の約0.2％。100人の中にお医者さんがいる確率は、およそ15％です。盲腸でも…」 | 「100人の中に〜確率は、およそ15％です。」の一文を削除 | **計算した確率は台本に入れない。** 事実1つ＋結果1つ（「医師は約0.2％。盲腸でも手術できる人がいなければ、命に関わります」）で止める |
| ⑧ | 「じゃあ、病気やケガをしたら。」 | 「じゃあ、病気やケガをしたら？」＋その後で改行 | **次の話題への切り出しは「？」で終え、改行**して答えを始める |
| ⑨ | 「でも、尽きたら、畑も家畜も、100人で回すしかない。」 | 「でも、その後は、畑も家畜も、100人で回すしかありません。」 | 「尽きたら」より「その後は」。**ですます調**（〜ありません） |
| ⑩ | 「そして、種として続けるには、数百人以上は必要と言われます。100人は、ぎりぎり足りない。」 | 「そしてなにより、種を存続させるには、数百人は必要と言われます。」 | **評価の一言（ぎりぎり足りない）は足さない。** 最後のデメリットは「そしてなにより」で、最も重要と示す。「以上」も外して簡潔に |
| ⑪ | 「だったら、100人はどう生きるのが正解か。バラバラにならず、一か所に集まって、缶詰を分け合って、火を囲んで暮らす。」 | 「つまり、みんなバラバラにならず一か所に集まって、缶詰を分け合って、電気の無い中、火を囲んで暮らすのです。」 | まとめは**問いかけではなく「つまり、〜」で結論**。**デメリットの語（電気）を回収**する。「〜のです」で説明調に締める |
| ⑫ | 「……そう。人類が100人になったら、最終的に、みんなでキャンプをします。」（その前は「それ、地球規模のキャンプです」を、ユーザーが「人類が100人になったら、最終的にみんなでキャンプをする」に変更依頼） | 「……つまり、人類が100人になったら、最終的に、みんなでキャンプになります。」 | オチは**気の利いた比喩の一言ではなく、冒頭の問いかけをそのまま受ける形**：「……つまり、○○が△△になったら、最終的に、〜になります。」接続は「そう」でなく「つまり」 |
| ⑬ | 行の途中で改行しない | 「たとえば電気。」「じゃあ、病気やケガをしたら？」の**直後で改行** | 話題の見出しになる語は**独立した行**にする（読み上げの間になる） |
| ⑭ | （誤字）「すまり」 | 原稿の誤字（つまり） | ユーザーの原稿でも誤字は直して報告する |

## 3. 文体の確定ルール（上の表のまとめ）
- ですます調に統一。常体の言い切り（〜消える・〜回すしかない）を混ぜない。
- 転換・まとめ・オチは「……でも実は、」「つまり、」「……つまり、」の**定型句**で始める。
- メリットは3つ、具体的・得を感じる語。デメリットは緊急性の高い順に3〜4つ。
- 数字は「約」「およそ」を付けた**単純な概算**まで。計算結果（確率など）は入れない。
- 1つの項目は「短い事実＋その結果」で終える。評価・感想の一言を足さない。
- 最後は冒頭の問いかけと同じ言葉の形に戻して落とす。

## 5. テーマ「もしも、摩擦が消えたら？」の修正履歴
| Claude案 | ユーザーの修正 | ルール |
|---|---|---|
| メリット3つ（荷物が軽い・スケートリンク・エンジン）→転換→デメリット | 「メリットはいらない。最初からネガティブでインパクトのある内容、どんどんスケールアップ」 | **テーマによっては型Aのメリット部を省き、ネガティブ始まりで「身近→巨大」へスケールアップする型**にする（立てない→つかめない→ネジ→止まれない→巨大なもの→山） |
| 最後に「風」（摩擦がなくなると暴風）／「ダム」 | 「風はイメージできない」「ダムはいらない」「山が流れ出すのを最後に」 | **視聴者が絵で想像できないもの・事実が曖昧なもの（風速の上限）は使わない。** 最大スケールは見慣れた巨大な絵（山が流れる）に |
| 飛行機の言及 | 駐機中の飛行機は不採用、「大仏」を採用 | 巨大なものは意外性のある絵（大仏・コンテナ）を好む |
| 最終稿 | 項目ごとに「まず／そして／それだけではありません／また／実は／さらに大変なのは」と接続詞で順に導入。オチは「つまり、〜わけです。」 | 型Aの「……でも実は」「……つまり、最終的に」は必須ではない。ユーザー最終稿は約383文字・約68秒（短めでもOKだった） |

### 追記：音声確認後のユーザー最終稿（摩擦）
- 「物がつかめない」の項目を削除（立てない→止まれない→巨大なものが動く→ネジ・釘→山）。順番を入れ替え、ネジを4番目に。
- 「砂粒どうし」→「砂粒同士」、山の文は「〜保っているので、それがなくなると〜」と1文にまとめた。
- まとめは「つまり、摩擦がなくなると、すべての物が低い方に流れ、山は崩れ、世界は、平らになるわけです。」でオチの二重（「……つまり、最終的に」）を廃止し、1文で締める。
- ルール：項目は削ってテンポを上げてよい。オチは1文のまとめで締める型もOK。

### 追記：映像制作中のオチの差し替え（摩擦）
- 「世界は、平らになるわけです」→「地面は平らになり、全てのものは低い方に流れ、世界は海に沈みます」。映像でラストを地球規模まで引いたあと、ユーザーが「海に沈む」をオチに採用（世界が平らになれば陸は海に沈む＝事実とも合う）。
- 音声は最後の一文だけ生成し直し、前の音声の 52.8 秒につないだ（全文を作り直すと映像のタイミングがすべてずれるため）。
- ルール：オチは「平らになる」のような状態より、**目に見える結末（海に沈む）**のほうが好まれる。映像の制作中にオチが変わったら、最後の一文だけ差し替える。

## 6. テーマ「もしも北朝鮮と戦争になったら」で追加された型C（予想→対策の繰り返し→FP相談オチ）
- 指示：「視聴者が思う起きそうなこと → でもこんなふうに対策される」を繰り返すストーリーにする。例：ミサイル発射→迎撃→船で攻めてきたら？→…。
- 最後は「安定した未来のため、資産形成やライフリスクは【ファイナンシャルプランナーに相談】」につなげ、**シリアス→最後だけユーモア**にする。
- ルール：対策は一般的な言い方に留め、成功率などの数字は入れない。実在の国・民族を揶揄しない。オチの商品・サービスは特定の金融商品を勧めない（FP相談の一般的な案内まで）。

### 追記：型C「北朝鮮」最終稿（ユーザー修正）
- 「攻める側に5倍の戦力」→ 通説に合わせ**3倍**に修正（根拠のない数字は使わない）。「もしと」は誤字として「もし、」に。
- サイバー攻撃・Jアラート避難の項目は削除。オチは冒頭の問いに戻す形をやめ、「お財布は守れません」→コメント誘導（「FP」とコメント）に変更。
- ルール：型Cのオチは、ユーザーの意向で**行動誘導（コメントしてね）で終えてよい**。
