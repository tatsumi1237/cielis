# もしもリール②：品質基準v2で動画を作る（moshimo-video-build）

3スキルの2番目。入力は `moshimo-storyboard` で確定した構成表。出力は **mp4（縦1080×1920・30fps・BGM/効果音付き・ナレーションなし）**。投稿文は `moshimo-post-writer` で同じ返信に付ける。
**生成AIツールも素材ファイルも使わない。** 映像＝Three.js(r160)＋HTML/CSS、音＝numpy/scipy合成、書き出し＝Playwright(headless Chromium)の1フレームずつ撮影→ffmpeg。

> **品質基準v2（2026-10 南海トラフ冒頭で確立・ユーザー絶賛）が標準。**
> 旧方式（`models.js` の角ばったモデルを `renderer.render` で直接描く）は「壊滅的に低品質」と却下された。**新しい動画はすべて v2 の土台（`assets/hq/`）で作る。**
> 合格した完成例：`examples/hq-opening/`（夕方の大通りを歩く主人公→スマホの緊急地震速報アップ、6秒）。`frames.jpg` が目標の見た目。

## 手順
1. **準備**：`bash build-hq.sh <workdir>`。`python -c "import numpy,scipy"`（無ければ `pip install numpy scipy`）
2. **scene.js を書く**（`examples/hq-opening/scene-opening.js` を起点に）
   - シーンは `SC.xxx=(()=>{...return {s,update(T,..)}})()`。**`renderFrame(T)` は T だけから全状態を計算**。乱数は `mulberry32(固定シード)`／`RK`
   - **描画は必ず `PP.render(scene,CAM,{th,u:{ex,bs,vig,sat,con,tm:T}})`**。手元・前景アップは `{fg:前景シーン,dof:1}` で背景をぼかす
   - 末尾は「フォントを `document.fonts.load` で読み込む → canvas文字を描く → `window.ready=true`」の非同期初期化（例の末尾をそのまま使う）
3. **結合**：`bash build-hq.sh <workdir> scene.js`（＝head + base + models + hq-core + hq-city + hq-phone + scene）
4. **代表画像**：`SCENE=video.html node render.js t test t1,t2,...` → `bash sheet.sh t s.jpg 6` → **1枚は原寸でも Read して目視** → 直す → SendUserFile(render)。**承認を得てから全編へ**
5. **全編書き出し**：v2は1フレーム約4〜5秒。**8並列**で `nohup node render2.js fr 30 開始 終了 &`。待つときは長いsleepループを1回で回さず、短い確認を挟む（ユーザーが割り込めるように）。枚数＝尺×30を確認、不足範囲だけ再実行
6. **音**：待っている間に `python audio.py` → `audio.wav`
7. **合成**：`ffmpeg -y -framerate 30 -i fr/f_%04d.jpg -i audio.wav -c:v libx264 -pix_fmt yuv420p -crf 18 -preset veryfast -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4`
8. **検査**：`select=...,scale=360:640,tile=Nx1` で冒頭・各カット・最終フレームを抜き出して目視
9. **納品**：SendUserFile(render)（**30MB超はスマホに届かない**ので、`-b:v 4300k` などで30MB未満にした版も作る）。投稿文は `moshimo-workflow` の⑥で、ユーザーが「完成」と言ってから作る。新しく作った部品は `assets/hq/` に足し、このSKILLに追記

## 品質基準v2（必須・すべて守る）
### 画づくり
- **時間帯はユーザーの指定に合わせる**（「明るく色鮮やかに」なら `TODP.day`）。昼は彩度1.28・ビネット弱め
- **ポスト処理を必ず通す**：HDRで描いて `PP.render`。目安（夕方の街）`th:1.6, ex:0.92, bs:0.55, vig:0.65, sat:1.12, con:1.12`／手元アップ `th:1.9, ex:0.9, bs:0.38, vig:0.7`。白飛び・霞みすぎは `ex` を下げ、霧を遠ざける
- **空は `skyDome`＋`envFrom` で環境光**（ガラス・金属・車に空が映る）。霧は空の地平色に合わせ、遠く（near 150〜, far 900〜）に置く。近景が霞んで白っぽくなったら霧が近すぎる
- **光は1つの物語に**：夕方なら低い太陽（強さ3〜3.5）＋弱い半球光（0.4前後）で長い影と逆光のリム。影は4096・PCFSoft。太陽の光輪をタイトルの真後ろに置かない
- **画面の密度**：建物は窓・1階店舗・看板・縦看板まで作る。街路樹・街灯・信号・ガードレール・車・人で、手前・中景・遠景の3層を埋める。光の粒（加算合成）で空気感
- **色**：暖色のハイライト＋寒色の影（`lift`/`gain`）。地面が紫っぽくなったらテクスチャを暖色寄りに
### 人物
- 人物は **`person2()` だけ**（関節付きのカプセル体・目・眉・鼻・耳・髪・コート・バッグ）。旧 `human()`/`human({hd})` は使わない
- 歩く人は **`walk(p,位相,振幅)`**（膝の曲げ・腕振り・腰の上下・胴のひねり）。止まるときは振幅を `smooth` で0へ。**群衆は主人公の周り数メートル以内にも置く**（まばらだと寂しい）。進行方向の人が主人公とぶつからないよう歩道のレーンを分ける
- 主人公は**色で目立たせる**（例：ベージュのコート）。まわりは落ち着いた色
### カメラ（映画的に）
- **主人公の視点で物語る**：追従ドリー、ローアングルで見上げる、肩越し（OTS）＋背景ぼかしの手元アップ。固定カメラ・真上からの俯瞰の連続は不可
- 冒頭は**ローアングルの追従**（高さ約1.95m、主人公の4.5m前、上向き約14°）：上半分にビルと空、中央に文字、**主人公は文字の下（頭がy≈1400）**
- カメラには微小な揺れ（手持ち感：sin で数mm〜数cm）。近いカットは寄りながら終える
- 隣り合うカットで、画角（引き／寄り）・光（逆光／順光）・色を変える
### 文字デザイン（`head.html` のクラスを使う）
- 冒頭（カット1・3秒）：**画面中央**に `#ttl`（`SIMULATION` の小見出し＝Oswald・字間0.42em・両側に細線／「もしも」80px／**キーワード178px：しっぽり明朝B1 800・白→金→朱のグラデ＋影と光彩**／後半80px）と `#cd`（ラベル36px・字間0.55em／**数字＝Oswald 600 250px・白＋赤い多重グロー**／「秒」／光る進行バー＋白い光点）。中央に楕円の暗い陰影 `#vig`
- **カウントダウンは3.00→0.00**（小数2桁、毎秒の頭で数字が小さく脈打つ）。0になる瞬間にカット2へ
- カット2以降：上部に1行タイトル `#ttl2`（50px・キーワードはグラデ）＋小さな経過時間。見出し `#hd`（しっぽり明朝86px・キーワードは金→朱のグラデ）y≈1190、補足は暗い角丸の帯
- 起点の瞬間は赤い閃光（0.18秒）。通常の切替は直切り
- IGセーフゾーン：上0–250・下1700–1920・右下アイコン帯に重要情報を置かない。注記 `#note` は y≈1630
### 尺
- **カット1＝3秒（起点の3秒前からカウントダウン）／カット2＝3秒／カット3以降＝4秒以下／最後＝締めの問い＋フォロー誘導をまとめた1カット・1秒**

## 新しい部品を作るとき
- `hq-core.js` の流儀に合わせる：`SM()`（MeshStandard・flatShadingなし）、曲面は Capsule/Sphere/Lathe/Extrude（角丸）で作る。**箱だけで主役を作らない**
- 画面・看板の文字は canvas（高解像度、Webフォントを読み込んでから描く）→ `emissiveMap`
- 前景アップ（手・小物）は前景シーンに分けて `fg` で重ねる（背景は自動でぼける）
- **名前の衝突に注意**：`models.js`/`base.js` に `person` `tree` `SHOPS` などがある。新しいトップレベル名は `xxx2` などにする（衝突するとページが止まり、ready待ちでタイムアウトする）
- 作った部品は `assets/hq/` に追記し、この表に1行足す

## 音の設計
- ナレーションなし、BGM＋効果音のみ。BGMは1本の小節グリッドで連続生成。不穏系は Dm パッド
- 冒頭の型（`audio-opening.py`）：街のざわめき＋車＋主人公の足音／**カウントダウンは毎秒の低い鼓動＋時計の音＋上昇する緊張音**／起点の直前0.1秒の無音／起点で警告音（**汎用の2音交互パルス。本物の緊急地震速報チャイムなど実在の警報音は使わない**）＋周囲の端末の音を少しずらして重ねる＋低い衝撃音
- 場面頭＝whoosh、見出し＝pop、山場＝crash/thud、締め＝bell。カットごとの環境音を1〜2個
- 仕上げ：1秒ごとのRMSで極端な無音がないか確認、tanhで軽くリミット

## よくある失敗
- WebGL：Chromium に `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`。three は 0.160.0、`three.min.js`（ES module は file:// で CORS エラー）
- r160 は RenderTarget に描くとトーンマップされない → 最終パスでACESとsRGB変換をしている（`PP`）。`renderer.render` を直接画面に描くと色が変わる
- Webフォントは使う文字を `document.fonts.load(font,text)` で先に読み込まないと、canvas文字が既定フォントになる
- 霧が近い／太陽の光輪が大きい／露出が高い → 全体が白く霞む。`ex` を下げ、霧を遠くへ、光輪を小さく
- 前景の手が赤く光りすぎる → 画面の照り返し（PointLight）は0.05前後、ブルームの閾値を上げる
- 主人公が文字の後ろに隠れる → カメラを上向きにして主人公を文字の下へ
- 手前の街路樹の大きな葉の塊が画面をふさぐ → カメラ付近には置かない
- 長い並列書き出しが止まる（アプリ終了など）→ 不足フレームを数えて、その範囲だけ再実行
- ffmpeg は `-preset veryfast`
